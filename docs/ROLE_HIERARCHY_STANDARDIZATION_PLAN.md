# 👥 LeadMaster CRM 전사 4대 표준 등급 및 역할 체계 (RBAC) 정립 기획서

> **문서 번호**: LM-SPEC-202611-ROLE-HIERARCHY-v1.0  
> **기획 목적**: 사이트 전체에 분산·혼재되어 있던 역할 명칭과 등급 체계를 분석하고, TM 센터의 실제 조직 및 기능에 최적화된 **4대 표준 등급 체계(대표이사 · 총괄관리자 · 팀장 · 상담원)**로 완전 일원화  
> **핵심 과제**: 팀 관리 페이지 역할 드롭다운에서 "총괄관리자"가 누락되어 3개만 뜨던 문제를 해결하고, 사이트 전역(사이드바, 헤더, 배정, 정산, 보안)의 직급/권한 UI를 통일

## 1. 현황 진단: 왜 지금은 "상담원, 관리자, 대표" 3개만 뜨는가?

```
[현재 시스템 내부 구조 (AS-IS)]
• DB 컬럼 (role): 'owner' | 'admin' | 'agent' (3개만 존재)
• 팀 페이지 역할 드롭다운: <select> 안에 'agent'(상담원), 'admin'(관리자), 'owner'(대표)만 하드코딩
• 문제의 원인: 
  - 백엔드와 모달 내부에는 이미 'Tier 1(플로어 팀장)', 'Tier 2(수석 팀장)', 'Tier 3(총괄 실장)'이라는 3단계 세부 권한이 구현되어 있으나,
  - 메인 드롭다운이 최상위 3개 role만 노출하고 있어 "총괄관리자"를 직관적으로 선택할 수 없음.
  - 대표 입장에서 "우리 회사는 대표 - 총괄관리자 - 팀장 - 상담원 4단계인데 왜 총괄관리자가 없지?"라는 극심한 혼선 발생.
```

## 2. TM 센터 환경 분석 기반: 4대 표준 등급 및 권한 체계 정의

실제 10~100인 규모의 B2B 법률/금융 TM 센터의 경영 및 현장 워크플로우에 최적화된 **4대 표준 등급(RBAC)**을 확립합니다.

```
👑 1. 대표이사 (CEO / Owner)
   └─ 전사 경영 · 손익 P&L · 수수료 계약 · 법적 총괄
   
🎖️ 2. 총괄 관리자 (Center Director / General Admin)
   └─ 센터 총괄 · DB 원가 · 파트너 청구 대사 · 전사 배정 룰 · 인사 통제
   
🛡️ 3. 관리자 / 팀장 (Team Leader / Admin)
   └─ 소속 팀 현장 지휘 · 실시간 호 감청 · 팀원 수당 검토 · 팀장 오버라이드
   
🎧 4. 전문 상담원 (Agent)
   └─ 본인 배정 고객 아웃바운드 콜 · 간편콜/일반 모드 · 본인 실적/인센티브 확인
```

### 2.1 4대 등급별 상세 역할 및 자격 기준

| 등급 (표준 명칭) | 공식 UI 뱃지 | 시스템 매핑 | 주 스코프 (Scope) | 핵심 역할 및 책임 |
|---|---|---|---|---|
| **1. 대표이사** | `👑 대표이사` | `owner` | **전사 (Company All)** | • 회사 총괄 경영, 법적 책임, 라이선스 좌석 결제<br>• 전사 극비 손익(P&L), 영업이익, 고정비 장부<br>• 제휴 로펌 수임 수수료율(%) 계약 체결<br>• 데이터 백업 다운로드 및 영구 파기 전권 |
| **2. 총괄 관리자** | `🎖️ 총괄 관리자` | `admin` (Tier 3) | **전사 운영 (Operations)** | • 센터 전사 운영 지휘 및 총괄 실장 역할<br>• DB 구입비용 대장 및 유입 채널별 단가 분석<br>• 파트너 정산 세금계산서 청구/수금 2단계 마감<br>• 전사 팀원 초대/정지, 보안 프로필(워터마크) 통제<br>• 텔레그램 연동 관제 센터 전사 승인 및 공지 하달 |
| **3. 관리자 (팀장)** | `🛡️ 팀장` | `admin` (Tier 1~2) | **소속 팀 (Team Only)** | • 1개 팀(5~15명)의 현장 실무 지휘<br>• 소속 팀원 리드 재배정, 실시간 모니터링, 녹취 청취<br>• 소속 팀원 수당 검토 및 **본인 팀장 오버라이딩 수당** 확인<br>• 팀 공지 및 팀원 대상 업무 지시 하달 |
| **4. 전문 상담원** | `🎧 상담원` | `agent` | **본인 리드 (Self Only)** | • 본인에게 배정된 고객 아웃바운드/인바운드 콜 수행<br>• 상담 일지 작성, 계약 성약 처리, 간편콜 모드 활용<br>• 본인 당월 계약 건수 및 개인 인센티브 정산표 열람<br>• 개인정보 마스킹(전화번호 숨김) 및 보안 프로필 준수 |

## 4. UI/UX 개선안: 팀 관리 페이지 및 사이트 전역 통일

### 4.1 스크린샷 영역(팀 페이지 멤버 목록) 드롭다운 개편안

기존의 단순 3개 옵션 대신, 직관적인 **4대 표준 등급 선택기**로 개편합니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│ 역할 선택 드롭다운 (개편 TO-BE)                                        │
├────────────────────────────────────────────────────────────────────────┤
│ [ 🎧 상담원               ] ➔ 일반 상담원 모드                          │
│ [ 🛡️ 팀장 (중간 관리자)     ] ➔ 담당 팀 현장 관리 권한 (Tier 1 자동 부여)    │
│ [ 🎖️ 총괄 관리자 (센터장)   ] ➔ 전사 운영 권한 원클릭 부여 (Tier 3 자동 부여) │
│ [ 👑 대표이사             ] ➔ 전사 최고 책임자 (대표 본인만 변경 가능)    │
└────────────────────────────────────────────────────────────────────────┘
```

* **원클릭 총괄관리자 승격**: 
  * 드롭다운에서 `🎖️ 총괄 관리자`를 선택하는 즉시 백엔드에서 `role: 'admin'`, `adminPermissions.tier: 3`으로 자동 설정되어, 복잡한 모달을 일일이 열지 않고도 원클릭으로 총괄실장을 임명할 수 있습니다.
* **팀장 선택 시**:
  * `🛡️ 팀장`을 선택하면 기본 Tier 1(플로어 팀장) 권한이 부여되며, 우측에 `[⚙️ Tier 상세 설정]` 버튼이 유지되어 필요 시 세부 스위치를 개별 조율할 수 있습니다.
