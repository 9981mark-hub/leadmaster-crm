# 리드마스터 시범 운영 안내서 (v1, 2026-11-01)

고객사 관리자 1명 + 상담원 3~5명으로 1~2주 시범 운영할 때 쓰는 순서입니다.
웹 주소: `https://9981mark-hub.github.io/leadmaster-crm/` (호스팅을 옮기면 바뀜)
앱 설치 파일: `https://9981mark-hub.github.io/leadmaster-crm/app/LeadMaster.apk`

---

## 1. 본사(HOST)가 할 일

1. 웹에 9981mark@gmail.com 으로 로그인 → 왼쪽 **회사 관리**
2. **새 고객 회사**에 회사 이름과 대표의 구글 이메일 입력 → **회사 만들기**
3. 대표에게 웹 주소를 보내고 "그 구글 계정으로 로그인하세요"라고 안내 (초대 14일 유효)
4. 목록에서 대표 초대가 **가입함**으로 바뀌면 다음 단계는 대표가 진행

## 2. 고객사 대표(관리자)가 할 일

### 2-1. 텔레그램 봇 만들기 (회사당 1개, 10분)
1. 텔레그램에서 **@BotFather** 검색 → `/newbot` → 봇 이름·아이디 입력
2. 받은 **토큰**(`123456789:AA...`)을 복사
3. BotFather에서 `/setprivacy` → 방금 만든 봇 → **Disable** (방의 모든 메시지를 받기 위해 필요)
4. 웹 **팀 관리 → 텔레그램 봇 연결**에 토큰 붙여넣기 → 저장 → **웹훅 등록** → "연결됨" 확인
5. **우리 쪽 발신자 이름**에 우리 직원 텔레그램 이름을 적기 (이 이름이 쓴 글은 피드백으로 수집하지 않음)

### 2-2. 변호사 사무실(거래처) 등록
1. 각 변호사 사무실 텔레그램 방에 **회사 봇을 초대** (방 관리자 협조 필요)
2. 웹 **설정 → 거래처**에서 거래처 추가 (새 회사는 거래처가 비어 있습니다)
3. 거래처 편집 → **텔레그램 수신 연동**에서 방 고르기 → **연결 시험**(방에 시험 글이 올라감) → **저장**
   - 목록에 방이 안 보이면 그 방에 아무 메시지나 한 번 보낸 뒤 새로고침
4. 접수서 양식(요약 템플릿)과 수수료 규칙도 거래처마다 설정

### 2-3. 상담원 초대·배정
1. **팀 관리 → 새 멤버 초대**: 상담원 구글 이메일, 표시 이름, 역할 "상담원"
2. 리드가 들어오면 **리드 배정**에서 고르고 배정하거나 **순번 나눠주기**
3. 상담원은 **본인에게 배정된 리드만** 봅니다. 상담원이 직접 등록한 리드는 자동으로 본인 배정.

## 3. 상담원 폰 설치 (1인 10분)

1. 폰 크롬에서 앱 설치 파일 주소 열기 → 다운로드 → 설치
   - "출처를 알 수 없는 앱" 경고 → **설정 → 이 출처 허용** → 설치
   - Play 프로텍트 경고가 뜨면 **무시하고 설치**
2. 앱 열기 → 앱 화면에서 **구글 로그인** (초대받은 그 계정)
3. **권한 점검** 화면이 뜨면 위에서부터 빨간 항목(✗)을 모두 눌러 허용
   - 전화·통화기록·문자 → 모두 허용
   - 다른 앱 위에 표시 → LeadMaster 켜기
   - 발신자 정보 앱 → LeadMaster 선택
   - 알림 → 허용
   - (권장) 바로 걸기, 배터리 최적화 제외, 전체 화면 알림, 앱 업데이트 설치 허용
4. 모두 ✓가 되면 닫기. 나중에 다시 보려면 앱 오른쪽 위 메뉴 → **권한 점검**
5. 시험: PC 웹에서 배정된 리드의 **전화 버튼** → 폰 다이얼러가 바로 뜨는지 / **문자** → 폰 문자 앱이 열리는지

### 앱 업데이트
새 버전이 나오면 앱을 열 때 하루 한 번 "새 버전" 안내가 뜹니다. **설치**를 누르면 됩니다.
바로 확인하려면 메뉴 → **앱 업데이트 확인**. (데이터는 그대로)

## 5. 자주 생기는 문제

| 증상 | 확인 |
|---|---|
| PC에서 전화 버튼을 눌러도 폰이 반응 없음 | 앱에 로그인했는지(상태 표시줄 "로그인 필요"), 권한 점검 ✓, 인터넷 연결 |
| 전화 올 때 팝업이 안 뜸 | 권한 점검: 다른 앱 위에 표시, 발신자 정보 앱, 배터리 최적화 제외 / 그 번호가 배정된 리드인지 |
| 삼성 업데이트 후 팝업이 안 뜸 | 업데이트 후 "발신자 정보 앱"이 풀리는 경우가 있음 → 권한 점검에서 다시 선택 |
| 상담원 화면에 리드가 없음 | 관리자가 배정했는지 (팀 관리 → 리드 배정) |
| 텔레그램 전달이 안 됨 | 거래처에 방이 선택됐는지, 봇이 그 방에 있는지 (설정 → 거래처 → 연결 시험) |
| 사무실 답장이 리드에 연결 안 됨 | 봇이 보낸 글에 **답장**으로 달았는지. 그냥 새 글이면 고객 이름으로 찾습니다 |

## 6. 개인정보

- 상담원 폰은 **배정된 리드 번호의 통화·문자 기록만** 서버에 올립니다. 개인 통화는 올리지 않습니다.
- 관리자 폰은 모든 통화·문자 기록을 올립니다 (본사와 같은 방식).
- 회사 간 데이터는 완전히 분리되어 다른 회사는 볼 수 없습니다.
