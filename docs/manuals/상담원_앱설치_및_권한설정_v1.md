# 상담원 안드로이드 앱 설치 및 권한 설정 가이드 (v1.0)
> **대상**: 리드마스터 모바일 앱을 사용하는 실무 상담원  
> **소요 시간**: 약 3분 내외  
> **필수 기종**: 안드로이드 10 이상 스마트폰 (삼성 갤럭시 권장)

---

## 📱 1. 앱 다운로드 및 설치 (1분)

1. 스마트폰에서 **Chrome(크롬)** 브라우저를 열고 아래 주소로 접속하거나 링크를 터치합니다:
   👉 **`https://9981mark-hub.github.io/leadmaster-crm/app/LeadMaster.apk`**
2. **"다운로드한 파일이 유해할 수 있습니다"** 경고창이 나타나면:
   - 당황하지 마시고 **[무시하고 다운로드]** 또는 **[다운로드 계속]**을 누릅니다.
   - *(사내 업무용 정식 서명 키로 제작된 안전한 앱입니다)*
3. 다운로드 완료 후 **`LeadMaster.apk`** 파일을 터치하여 설치를 진행합니다.
4. **"보안상의 이유로 이 출처의 알 수 없는 앱을 설치할 수 없습니다"** 팝업 발생 시:
   - **[설정]** 터치 ➔ **"이 출처의 앱 허용"** 스위치를 **ON(파란색)**으로 켭니다 ➔ 뒤로 가기 후 **[설치]**를 터치합니다.
5. **Google Play 프로텍트 경고** ("확인되지 않은 앱 차단됨") 팝업 발생 시:
   - 화면 하단의 **[세부정보 더보기]** 또는 **[세부정보]**를 터치합니다.
   - 아래쪽에 나타나는 **`[무시하고 설치]`**를 누르면 설치가 완료됩니다.

## 🔑 2. 최초 실행 및 구글 로그인 (30초)

1. 바탕화면에 생성된 **`리드마스터(LeadMaster)`** 아이콘을 눌러 실행합니다.
2. 메인 화면에서 **`[Google 계정으로 로그인]`**을 누릅니다.
3. 회사 관리자(팀장님)에게 전달했던 **본인의 구글 계정**을 선택합니다.
4. 소속 회사명과 본인 이름이 표시되며 메인 화면으로 진입합니다.

---

## ⚙️ 3. 필수 권한 5종 원터치 허용 (1분)

리드마스터 앱은 **자동 통화 발신, 통화 녹음 파일 자동 수집, 통화 중 골든타임 재통화 예약** 기능을 제공합니다. 앱이 정상 작동하려면 아래 권한이 반드시 필요합니다:

### ① 통화 및 전화 권한
- **설정 방법**: 화면 안내에 따라 **`[앱 사용 중에만 허용]`** 또는 **`[항상 허용]`** 선택.
- **용도**: CRM 웹에서 [전화 걸기] 클릭 시 폰에서 0.1초 만에 자동 전화 발신.

### ② 오디오 및 저장공간(파일) 접근 권한
- **설정 방법**: "기기의 음악 및 오디오에 액세스하도록 허용" ➔ **`[허용]`** 선택.
- **용도**: 상담 통화 종료 후 저장된 녹음 파일을 찾아 사내 안전 스토리지로 자동 백업.

### ③ 다른 앱 위에 표시 (플로팅 콜 팝업)
- **설정 방법**: 설정 목록에서 **`리드마스터`**를 찾아 스위치를 **ON(켭니다)**.
- **용도**: 고객과 통화하는 도중 화면 위에 고객 정보와 `[⏰ 30분 뒤 재통화]`, `[1차 상담 메모]` 팝업을 띄워줍니다.

### ④ 배터리 사용량 최적화 중지 (절전 모드 예외)
- **설정 방법**: 시스템 팝업에서 **`[허용]`** 선택.
- **용도**: 화면이 꺼져 있어도 실시간 인입 알림과 웹 전화 요청을 누락 없이 즉시 수신.

### ⑤ 통화 녹음 자동 활성화 (삼성 기본 전화 앱)
- 삼성 기본 **[전화]** 앱 실행 ➔ 우측 상단 **점 3개(⋮)** ➔ **[설정]** ➔ **[통화 녹음]**
- **"통화 자동 녹음"**을 **`ON(모든 번호)`**으로 설정합니다.

## ❓ 자주 묻는 질문 (FAQ)

**Q1. 통화가 끝나도 녹음 파일이 웹에 안 올라와요.**
- 삼성 전화 앱에서 "통화 자동 녹음"이 켜져 있는지 확인하십시오.
- 너무 짧은 통화(20초 미만 또는 부재중)는 사내 정책에 따라 자동 필터링되어 백업되지 않습니다.

**Q2. 개인적인 가족/지인 통화도 회사로 올라가나요?**
- **절대 올라가지 않습니다.** 리드마스터 앱은 DB에 등록된 고객 리드 번호와 일치하는 통화 녹음만 선별하여 안전하게 백업합니다. 개인 통화는 폰에만 남습니다.

**Q3. 앱 업데이트는 어떻게 하나요?**
- 새 버전이 출시되면 앱 실행 시 **"새 버전 업데이트가 있습니다"** 알림창이 뜹니다. `[지금 업데이트]`를 누르면 10초 만에 자동으로 최신 버전으로 갱신됩니다.
