## 3. 기종별 백그라운드 절전 모드 예외 설정 가이드 (삼성 One UI)

상담원이 화면을 꺼두거나 다른 앱을 사용할 때도 웹 CRM에서 누른 전화 발신 명령이 0.1초 만에 실행되려면, 삼성전자의 **'디바이스 케어 배터리 절전 예외'** 설정이 필요합니다.

### [설정 순서]
1. 폰 **[설정]** ➔ **[배터리]** (또는 **[디바이스 케어]**) ➔ **[백그라운드 사용 제한]** 터치.
2. **"절전 예외 앱"** (또는 **"절전 상태로 전환하지 않을 앱"**) 터치.
3. 우측 상단 **[+]** 버튼을 눌러 **`리드마스터(LeadMaster)`**를 선택하고 추가합니다.
4. 이제 화면이 꺼져 있거나 장시간 방치되어도 전화 요청이 즉시 수신됩니다.

## 4. 안드로이드 버전별 특이사항 및 해결책

### ① 안드로이드 13, 14, 15 (One UI 5.0, 6.0, 7.0)
- **알림 권한 (POST_NOTIFICATIONS)**: 앱 최초 실행 시 "알림을 보내도록 허용하시겠습니까?" ➔ **[허용]** 필수.
- **오디오 파일 권한 (READ_MEDIA_AUDIO)**: 기존 저장공간 권한 대신 '음악 및 오디오' 세부 권한으로 자동 승격됨.

### ② 안드로이드 10, 11, 12
- **저장공간 권한 (READ_EXTERNAL_STORAGE)**: 파일 관리자 권한 허용.
- Scoped Storage 예외 플래그(`requestLegacyExternalStorage=true`)가 정식 앱에 탑재되어 있어 정상 접근 가능.
