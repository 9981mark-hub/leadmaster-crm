# 고객사 관리자 온보딩 가이드 (v1.0)
> **대상**: 리드마스터 CRM을 도입한 고객사 대표(Owner) 및 실무 관리자(Admin)  
> **소요 시간**: 약 10분 내외

---

## 🚀 빠른 시작 5단계 요약

```
[1단계] 구글 계정으로 웹 최초 로그인 (초대 자동 수락)
   ⬇
[2단계] 사내 텔레그램 알림 봇 등록 (5분 소요)
   ⬇
[3단계] 거래처(법무법인 / 변호사 사무실) 등록
   ⬇
[4단계] 상담원 대량 초대 (엑셀 명단 복사 ➔ 10초 완료)
   ⬇
[5단계] 상담원들에게 안드로이드 정식 APK 링크 배포
```

---

## 1단계: 웹 CRM 최초 로그인

1. 전달받은 **리드마스터 웹 주소**(`https://9981mark-hub.github.io/leadmaster-crm/`)에 접속합니다.
2. 계약 시 등록하신 **대표님 구글 계정**으로 `[Google 계정으로 로그인]`을 클릭합니다.
3. 로그인 즉시 플랫폼에서 발송된 대표 권한 초대가 자동으로 수락되며, 귀사의 독립된 테넌트 전용 화면으로 연결됩니다.
   - *확인*: 우측 상단 프로필에서 `[회사명] · 대표` 배지가 표시되는지 확인하십시오.

---

## 2단계: 텔레그램 알림 봇 연동 (5분)

실시간 고객 인입, 부재 알람, 사무장 인계 알람을 팀원들과 수신할 텔레그램 봇을 연결합니다.

1. 스마트폰 또는 PC 텔레그램에서 `@BotFather`를 검색합니다.
2. `/newbot`을 전송하고, 봇 이름(예: `○○컨설팅 알림봇`)과 사용자명(예: `oo_consulting_bot`)을 입력합니다.
3. BotFather가 발급해 준 **HTTP API Token** (예: `7123456789:AAH...`)을 복사합니다.
4. 리드마스터 웹 메뉴 **[팀 관리] ➔ [텔레그램 봇 설정]**에 토큰을 붙여넣고 `[연결 저장]`을 누릅니다.
5. 사내 텔레그램 단체방에 해당 봇을 초대한 뒤, `[테스트 메시지 발송]`을 눌러 정상 수신되는지 확인합니다.

---

## 3단계: 거래처 (변호사 사무실 / 파트너) 등록

수임 계약 체결 시 사건을 이첩하거나 수수료를 정산할 파트너사를 등록합니다.

1. **[설정] ➔ [거래처(파트너) 관리]**로 이동합니다.
2. `[+ 파트너 등록]`을 클릭하여 법무법인명, 대표 변호사/사무장 성명, 정산 요율, 수신 텔레그램 방 ID를 입력합니다.
3. 등록 완료 즉시 사무장 인계 큐에서 해당 파트너사로 원클릭 전달이 가능해집니다.

---

## 4단계: 상담원 대량 초대 (10~50명)

상담원들을 한 명씩 수동으로 등록할 필요 없이, 엑셀에서 명단을 한 번에 붙여넣습니다.

1. **[팀 관리] ➔ [멤버 관리]** 탭으로 이동합니다.
2. 상단의 **`[👥 상담원 대량 초대 (10~50명)]`** 파란색 버튼을 클릭합니다.
3. 엑셀의 `이름`과 `구글 이메일` 열을 복사(`Ctrl+C`)하여 입력창에 그대로 붙여넣습니다(`Ctrl+V`).
   ```text
   홍길동   hong@gmail.com
   이순신   lee@gmail.com
   강감찬   kang@gmail.com
   ```
4. 실시간 감지 창에서 `유효 초대 가능 X명` 확인 후 **`[X명 일괄 초대 발송]`**을 클릭합니다.
5. 초대를 받은 상담원들은 본인 폰에서 구글 로그인만 하면 즉시 귀사 소속 상담원으로 배치됩니다.

---

## 5단계: DB 자동 배분 및 스마트 순환 설정

방치되거나 통화가 안 되는 리드를 자동으로 회수하고 재배분하는 정책을 켭니다.

1. **[팀 관리] ➔ [배분 및 순환]** 탭으로 이동합니다.
2. **미처리 DB 자동 회수 주기**: 기본 24시간 (상담원이 24시간 동안 통화나 메모를 남기지 않으면 자동 회수).
3. **부재중 교차 셔플**: `3회 이상 부재중 DB`를 다른 상담원에게 교차 배분하여 연결률을 극대화하도록 활성화합니다.

---

## 6단계: 상담원들에게 앱 설치 안내 배포

아래 메시지 템플릿을 복사하여 사내 단체방(카카오톡 / 텔레그램)에 공지하십시오:

```text
[리드마스터 CRM 상담원 앱 설치 안내]

상담원 여러분 안녕하십니까. 
보다 편리한 통화 녹음 자동 동기화 및 원클릭 콜 업무를 위해 리드마스터 모바일 앱을 설치해 주시기 바랍니다.

1. 앱 다운로드 주소: https://9981mark-hub.github.io/leadmaster-crm/app/LeadMaster.apk
2. 설치 시 '출처를 알 수 없는 앱 설치 허용' 및 Google Play 프로텍트 경고 시 '무시하고 설치'를 눌러주세요.
3. 앱 실행 후 회사에 등록된 본인의 [Google 계정]으로 로그인하시면 권한 설정 가이드가 실행됩니다.

* 문의: 관리자
```
