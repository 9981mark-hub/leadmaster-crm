## 🚨 오픈 전 필수 조치 (블로커)

> [!CAUTION]
> 아래 항목이 완료되지 않으면 오픈 불가

1. **Supabase Pro 전환** — 30명만 되어도 무료 플랜 대역폭(5GB) 초과 확실
2. **GitHub 비공개 전환** — 소스·키·토큰 공개 상태에서 고객사 투입 불가

4. **구글 OAuth 동의 화면** — 테스트 모드는 사용자 100명 제한 + 토큰 7일 만료
5. **개인정보 처리위탁 계약** — 고객사 고객 데이터(채무·소득) 보관 시 법적 필수
