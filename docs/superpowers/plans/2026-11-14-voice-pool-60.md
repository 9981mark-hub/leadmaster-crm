> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 1안 MS Edge-TTS(0원 무제한, 0.3초 초고속 반응)를 기반으로 3대 성우를 자연 성대 골든 레인지(-18Hz~+14Hz, 0.80x~1.18x) 내에서 60인의 고유 실전 페르소나(남성 38인 + 여성 22인)로 정밀 분신시키고, 트레이닝 센터에 60인 퀵 셀렉터 및 무규칙 연동을 구현한다.

**Architecture:** 
1. `services/characterVoice60.ts`에 60인 전용 사운드 매트릭스(남성 38인, 여성 22인)와 매칭 헬퍼 함수를 신설한다.
2. `services/trainingProceduralEngine.ts`에서 연령/성별/성향별로 60인 보이스를 1:1 유기적으로 자동 배정하고 음향 파라미터(Pitch, Rate, 추임새)를 주입한다.
3. `pages/TrainingCenterPage.tsx` 좌측 음성 패널에 60인 모달 셀렉터를 장착하여 상담원이 60인 전원을 직접 골라듣고 실습할 수 있도록 UI를 확장한다.

**Tech Stack:** React 19, TypeScript, MS Edge-TTS API (`api/edge-tts.ts`), Lucide-react, Tailwind CSS.

## Global Constraints
- MS Edge-TTS 공식 한국어 성우는 3명(`ko-KR-InJoonNeural`, `ko-KR-SunHiNeural`, `ko-KR-HyunsuMultilingualNeural`)만 사용.
- 모든 캐릭터의 Pitch는 `[-18Hz, +14Hz]` 범위를 절대 벗어나지 않음 (기계음/외계인 소리 원천 방지).
- 모든 캐릭터의 말속도는 `[0.80x, 1.18x]` 범위를 절대 벗어나지 않음.
- 추가 서버 비용 0원 유지 및 동일 출처 `/api/edge-tts` 다이렉트 직결.
