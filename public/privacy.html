개인정보처리방침

시행일: 2026년 11월 10일 | 최종 수정: 2026년 11월 10일

리드마스터 CRM(이하 "서비스")은 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고 이와 관련한 고충을 신속하고 원활하게 처리할 수 있도록 다음과 같이 개인정보처리방침을 수립·공개합니다.

제1조 (개인정보의 처리 목적)

서비스는 다음의 목적을 위하여 개인정보를 처리합니다. 처리하는 개인정보는 다음의 목적 이외의 용도로는 이용되지 않으며, 이용 목적이 변경되는 경우에는 별도의 동의를 받는 등 필요한 조치를 이행합니다.

  1. 회원 가입 및 관리: 회원제 서비스 제공에 따른 본인 식별·인증, 회원자격 유지·관리, 서비스 부정이용 방지
  2. 서비스 제공: 고객 상담 관리(CRM), 통화·문자 기록 연동, 리드 배분 및 전달, 통화 녹음 보관 및 AI 요약, 통계 분석
  3. Google 계정 연동: Google 로그인을 통한 본인 인증, Google Drive 연동을 통한 통화 녹음 파일 보관

제2조 (처리하는 개인정보의 항목)

구분항목보유 기간
회원 정보이름, 이메일 주소, 프로필 사진 (Google 계정에서 제공)회원 탈퇴 시까지
서비스 이용 기록접속 일시, 접속 IP, 기능 사용 기록회사별 설정 (6개월~2년)
고객 상담 데이터고객 연락처, 상담 내용, 채무·소득 정보, 통화 녹음회사별 설정에 따름

제3조 (Google API 서비스 이용)

서비스는 Google API 서비스를 다음과 같이 이용합니다.

3-1. Google 로그인 (OAuth 2.0)

  • 수집 정보: 이름, 이메일 주소, 프로필 사진
  • 사용 목적: 서비스 로그인 및 본인 인증
  • 권한 범위: openid, email, profile

3-2. Google Drive 연동

  • 수집 정보: 연동된 Google Drive 폴더 정보, 업로드된 파일 메타데이터
  • 사용 목적: 통화 녹음 파일의 비공개 보관 및 재생
  • 권한 범위: drive.file (서비스가 생성하거나 사용자가 명시적으로 선택한 파일에만 접근)
  • 제한 사항: 사용자가 명시적으로 선택하거나 서비스가 생성한 파일 이외의 Google Drive 파일에는 접근하지 않습니다.
Google API 서비스 사용자 데이터 정책 준수
리드마스터 CRM의 Google API 서비스 이용 및 Google API 서비스로부터 수신한 정보의 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.

제4조 (개인정보의 제3자 제공)

서비스는 이용자의 개인정보를 제1조에서 명시한 범위 내에서만 처리하며, 이용자의 동의 없이 제3자에게 제공하지 않습니다. 다만, 다음의 경우에는 예외로 합니다.

  1. 이용자가 사전에 동의한 경우
  2. 법령에 의하여 요구되는 경우
  3. 서비스 제공에 관한 계약 이행을 위해 필요한 경우 (예: 고객사 관리자가 거래처에 상담 리드를 전달하는 업무)

제6조 (개인정보의 파기)

서비스는 개인정보의 보유 기간이 경과하거나 처리 목적이 달성된 경우에는 지체 없이 해당 개인정보를 파기합니다.

  • 전자적 파일: 복구 불가능한 방법으로 삭제
  • 회원 탈퇴 시: 해당 계정의 모든 개인정보를 즉시 파기
  • 고객사 계약 종료 시: 합의된 기간 내 모든 데이터 파기 또는 반환

제7조 (이용자의 권리·의무 및 행사 방법)

이용자는 서비스에 대해 언제든지 다음 각 호의 권리를 행사할 수 있습니다.

  1. 개인정보 열람 요구
  2. 오류 등이 있을 경우 정정 요구
  3. 삭제 요구
  4. 처리정지 요구
  5. Google 계정 연동 해제 (Google 계정 설정 → 보안 → 서드파티 앱 접근 관리)

제8조 (개인정보의 안전성 확보 조치)

서비스는 개인정보의 안전성 확보를 위해 다음과 같은 조치를 취하고 있습니다.

  • 모든 통신은 HTTPS/TLS로 암호화
  • 데이터베이스 접근 권한을 회사·역할별로 분리 (Row Level Security)
  • 접근 기록(열람·내보내기·삭제·재생) 자동 저장
  • 통화 녹음 파일은 Google Drive 비공개 저장, 서버 경유 재생
  • API 키 및 인증 토큰은 서버에서만 관리
  • 회사 간 데이터 완전 분리 (멀티테넌트 RLS)
